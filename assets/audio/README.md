播放策略：用户点击 `查看介绍` 进入弹层后，童谣音频会**自动开始播放**；同时弹层内的视频默认不自动播放，避免声音叠加。如需静音或重新播放，可使用控件。若浏览器自动播放策略被系统拦截，会静默忽略，由用户手动点播放。

各文件路径集中配置在 `js/spots/` 的地点数据中。音频统一使用 MP3；新增或替换前需检查文件完整性、响度和浏览器播放兼容性。
