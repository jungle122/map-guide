# 粤韵童行联动导览 H5

独立的纯静态联动地图项目，与现有“粤韵童行”微信小程序代码无关。

当前已接入黄连古村正式手绘地图、6 个童谣景点、9 个文化介绍点位及经团队整理的 GCJ-02 导航坐标。

## 本地打开

在本目录启动任意静态文件服务器，例如：

```powershell
python -m http.server 5500 --bind 0.0.0.0
```

电脑浏览器打开 `http://127.0.0.1:5500/`。项目没有 npm、构建步骤、后端或数据库。

开发坐标工具使用：

```text
http://127.0.0.1:5500/?debug=1
```

## 当前闭环

- 黄连古村正式手绘地图原始高清 JPG（8091 × 5669，未重新编码）
- 14 层 WebP DZI 静态瓦片，按缩放级别和可视区域加载；失败时自动切换普通单图模式
- 手机和电脑全屏地图界面
- 鼠标、触摸拖动，滚轮、双指和按钮缩放
- 6 个醒目的童谣景点热点和 9 个弱化展示的文化介绍点位
- 点击热点显示地点快捷卡片，可分别进入详情和导航选择
- 高德、百度、腾讯及 Apple 地图网页路线；Apple 地图仅在 Apple 设备显示
- 无坐标时明确提示“真实坐标待补充”，仍可复制地点名称
- 一个通用详情弹层展示正式图文、音频和视频
- 音视频互斥，关闭详情后暂停并清理
- 调试模式下可临时新增、删除、清空和恢复点位，也可点击地图放置、拖动热点微调，并复制单个或全部坐标；所有调整仅在当前页面生效，刷新后恢复

首批景点配置已拆分到 `js/spots/`：

- `shishijiao.js`：石狮脚（何诒燕堂码头）
- `tianhou-xiancan.js`：天后宫、先蠺庙
- `longshi.js`：黄连龙虱馆
- `jiyaxiang.js`：鸡鸭巷

## 正式资料替换

1. 使用 `?debug=1` 选择景点，或临时新增多个测试点，再通过点击或拖动大头针完成点位复核；调试操作不会修改项目文件。
2. 将复制出的 `x`、`y` 写回对应的 `js/spots/*.js`。
3. 坐标有更新时，同步核对 `longitude`、`latitude`、`navName` 和来源分享链接。
4. 在微信、安卓浏览器和 iPhone Safari 中分别测试地图浏览、媒体播放和导航跳转。

手绘地图百分比坐标与未来的真实经纬度必须分开保存，不能互相推算。

## 地图瓦片维护

网页默认读取 `assets/map/tiles/v3/huanglian.dzi`，OpenSeadragon 已作为静态文件保存在 `js/vendor/`，不需要 npm 或外部 CDN。

更换正式地图后，在安装了 libvips 的电脑执行：

```powershell
.\tools\generate-map-tiles.ps1 -Version v4 -VipsPath "C:\path\to\vips.exe"
```

生成脚本会验证 8091 × 5669 原图、DZI 描述、最高层瓦片数量和输出目录。版本目录不可覆盖；生成新版本后，还需要更新 `js/map-tiles.js` 中的 `TILE_SOURCE`。使用 `?map=legacy` 可以强制进入普通单图模式，便于新旧引擎对比。

## 最小验收

在电脑和真机微信中分别确认：地图可拖缩；6 个童谣热点与 9 个文化介绍点位均可点击；详情图文可见；媒体需要手动播放；切换媒体只保留一个播放；关闭详情后声音停止；四种地图按设备正确显示并进入对应地点路线；无经纬度时导航不会误跳转；调试工具只在 `?debug=1` 下出现。

## 部署提醒

备案审核期间不解析正式域名，也不提前通过中国内地服务器公开网站。备案成功后再配置 DNS、Nginx、HTTPS 和ICP备案信息，并保留离线包与演示录屏。

瓦片目录使用版本化路径，可配置一年不可变缓存；`index.html` 不应长期缓存。仓库提供了 `deploy/nginx-map-guide-cache.conf` 示例，合并到线上 Nginx 前必须先备份当前配置并运行 `nginx -t`。
