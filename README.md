# 粤韵童行互动导览 H5

独立的纯静态互动地图项目，与现有“悦韵童行”微信小程序代码无关。

> 当前是功能与视觉测试版。黄连古村底图清晰度有限，测试热点、区域、名称、介绍和媒体均不是正式资料，不可直接作为正式交付内容。

## 本地打开

在本目录启动任意静态文件服务器，例如：

```powershell
python -m http.server 5500 --bind 0.0.0.0
```

电脑浏览器打开 `http://127.0.0.1:5500/`。项目没有 npm、构建步骤、后端或数据库。

开发坐标工具使用：

```text
http://127.0.0.1:5500/?debug=1
```

## 当前闭环

- 1080 × 757 黄连古村临时测试底图
- 手机和电脑全屏地图界面
- 鼠标、触摸拖动，滚轮、双指和按钮缩放
- 3 个带常显名称的测试热点
- 2 个 SVG 测试区域
- 区域点亮、外围变暗和关联热点突出
- 点击热点显示地点快捷卡片，可分别进入详情和导航选择
- 高德、百度、腾讯及 Apple 地图选择界面；当前无真实坐标，不会执行跳转
- 无坐标时明确提示“真实坐标待补充”，仍可复制地点名称
- 一个通用详情弹层展示测试图文、音频和视频
- 音视频互斥，关闭详情后暂停并清理
- 调试模式下读取坐标、拖动热点和记录区域顶点

## 正式资料替换

1. 将正式地图原文件归档，并导出清晰的网页版本到 `assets/map/`。
2. 同步修改 `js/map.js` 的 `MAP_WIDTH`、`MAP_HEIGHT` 和 `css/map.css` 的 `.map-canvas` 尺寸。
3. 使用 `?debug=1` 重新标注热点与区域。
4. 在 `js/data.js` 替换测试热点，在 `js/regions.js` 替换测试区域。
5. 导入正式图片、音频、视频与封面，删除全部测试素材和占位提示。
6. 为每个景点核对可到达入口的真实经纬度，再接入各地图平台的正式导航链接并完成真机测试。

手绘地图百分比坐标与未来的真实经纬度必须分开保存，不能互相推算。

## 最小验收

在电脑和真机微信中分别确认：地图可拖缩；热点可点击；两个区域可点亮、切换和恢复全图；详情图文可见；媒体需要手动播放；切换媒体只保留一个播放；关闭详情后声音停止；调试工具只在 `?debug=1` 下出现。
